# __TITLE__

A PixiJS v8 + Vite + TypeScript game, created with Pixi Editor.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- `src/main.ts` creates the Pixi Application and loads the assets (`public/assets`).
- `src/scene.ts` builds the first screen.

Open this folder in Pixi Editor to move objects, change texts, colors and textures visually: the
editor writes the changes back into the code.
